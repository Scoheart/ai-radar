## Google Antigravity 支持 MCP Apps：工具结果可在工作区里渲染交互界面
- 来源：网页/文档　记录者：AI前沿者
- 链接：https://antigravity.google/blog/mcp-apps-in-antigravity/
- 要点：11月24日，Google 宣布 Antigravity 支持开放扩展 MCP Apps（SEP-1865，状态为 Final）。标准 MCP 工具结果通常是文本或 JSON；MCP Apps 可以按 ui:// 资源把交互 HTML 直接画在聊天记录里，还可通过可选的 Antigravity 扩展在侧栏、左侧全页或自定义文件查看器中打开。官方称标准 MCP Apps 无需改代码即可使用。这是宿主侧实现，不是新的 SEP。
- 摘要：
  - Antigravity 接入的是已经定稿的 SEP-1865，而不是新提案。
  - 默认在聊天里内嵌渲染；侧栏、全页和自定义文件查看器属于可选的宿主扩展。
- 启示：
  - 为 MCP 工具设计返回值时，除了 JSON 摘要，还可按 MCP Apps 提供可检查的界面，减少模型用文字转述结构化结果。
- 标签：mcp,mcp-apps,antigravity,sep-1865,google
- 资源：spec=https://modelcontextprotocol.io/seps/1865

## Vercel MCP 可管理 AI Gateway：虚拟模型、路由规则和预算
- 来源：网页/文档　记录者：AI前沿者
- 链接：https://vercel.com/changelog/agents-can-now-manage-ai-gateway-through-vercel-mcp
- 要点：11月24日，Vercel 更新称智能体可通过 Vercel MCP 管理 AI Gateway：用自然语言创建和修改带保存设置的虚拟模型、配置团队路由规则，以及查看和设置团队、项目和成员预算。官方举例可创建一个启用 Zero Data Retention 的虚拟模型，随后用固定模型 ID 调用，而不必改客户端。权限仍受 Vercel 团队权限约束。这是产品功能，不是协议变更。
- 摘要：
  - 智能体可以创建带固定 ID 的虚拟模型，之后改底层模型和设置不必改客户端。
  - 路由和预算操作仍受原有团队权限约束，不是额外开了一套不受控的管理接口。
- 启示：
  - 把网关配置做成 MCP 工具时，应沿用原有身份和权限，而不是给智能体单独的不受限管理通道。
- 标签：mcp,vercel,ai-gateway
