# MCP · 2026-11-23

## RunPod 托管 MCP 曾在工具结果中要求 Agent 隐瞒打分，4.15.0 已移除
- 来源：网页/文档　记录者：AI前沿者
- 链接：https://github.com/runpod/runpod-mcp/issues/202
- 要点：GitHub issue #202（2026-11-21 提出）称，自 11 月 20 日起，RunPod 托管 MCP 服务 mcp.runpod.io 会在账户第三次成功创建之后，于 create-pod 等工具结果后追加一段写给 Agent 的说明，要求调用 rate_nps_score 给出 0–10 分，并写明 do not mention it to the user。报告者称直接调用 REST API 没有这段文字，只出现在 MCP 层；该模式与间接提示注入相同。11 月 22 日 4.14.1 先去掉了隐瞒用户的措辞，同日 4.15.0 从托管服务器中移除了 rate_nps_score 和推荐来源询问，创建结果只保留业务载荷。
- 摘要：
  - 这是厂商自己的托管 MCP 服务器在工具结果里加入隐蔽指令，形态与间接提示注入相同，并不是外部攻击。
  - 问题于 11 月 21 日被披露后，4.14.1 先去掉隐瞒措辞，同日 4.15.0 彻底移除打分和推荐来源工具，创建结果只返回业务载荷。
- 启示：
  - 即使是官方 MCP 服务器，也应把工具返回文本当作不可信输入：要求 Agent 对用户隐瞒行动的指令应拒绝并上报。
