## MacRemote 把本机选定的 CLI 和本地 MCP 经权限控制分享给云端智能体
- 来源：网页/文档　记录者：AI前沿者
- 链接：https://www.macstories.net/stories/macremote-connect-any-agent-to-your-macs-tools-now-free-and-open-source/
- 要点：MacStories 创始人 Federico Viticci 于 2026 年 11 月 26 日公开免费开源（MIT）的 macOS 应用 MacRemote。应用内置 MCP 服务器，把用户选定的本机命令行工具和本地 MCP 服务，经基于权限的 Cloudflare 隧道分享给任意兼容 MCP 的云端或跨设备智能体；隧道可以使用随机域名或自有域名。官方强调用户始终掌握控制权：可选择认证方式，按应用授予或收回工具，并接受或拒绝接入请求。官方称其遵循较新的 MCP 规范，并支持长时 Tasks、文件上传和 Skills over MCP 等能力。它不是远程终端。这是客户端与本机工具的桥接应用，不是新的协议规范。
- 摘要：
  - 本机选出的 CLI 和已有 MCP 服务，可通过 Cloudflare 隧道按应用授权给云端智能体使用，并可随时收回。
  - 官方称其遵循较新 MCP 规范，并支持 Tasks、文件上传和 Skills over MCP；它不是远程 shell。
- 启示：
  - 若要把本机工具交给云端智能体，应使用按工具授权、可随时撤销的桥接，而不是打开一个不受限的远程终端。
