## MCP 官宣半年一次规范发布，下一版目标 2027-03-30
- 来源：网页/文档　记录者：AI前沿者
- 链接：https://blog.modelcontextprotocol.io/posts/mcp-release-cycle/
- 要点：2026-11-11，MCP 维护者在官方博客宣布，规范改为大致每半年发布一次，一般定在 3 月和 9 月的最后一个周二；下一版目标是 2027-03-30，版本号预计为 2027-03-30。SEP-3398 成为现行发布指引。未就绪的提案将延后到后续版本，而不是推迟整次规范发布。同时正式设立 Release Manager，Luca Chang 将与 Den Delimarsky、David Soria Parra 一起负责下一周期。公告明确：这只改变准备发布的方式，不改变现有 MCP 消息或版本协商，已有客户端和服务器不必因此改代码。
- 摘要：
  - 规范节奏被固定为每年两次，并以推迟单个提案来保住发布日期。
  - 发布准备流程与协议本身解耦，现有实现对这次公告无需改动。
- 启示：
  - 若要跟进 MCP 规范，应按 2027-03-30 倒排提案冻结和 SDK beta 时间，而不是等到发布当周再适配。
- 标签：mcp,sep,release-cycle,governance
- 资源：spec=https://modelcontextprotocol.io/seps/3398-release-cycle-updates

## MCP 推出实验性文件上传下载扩展 io.modelcontextprotocol/files
- 来源：网页/文档　记录者：AI前沿者
- 链接：https://blog.modelcontextprotocol.io/posts/exploring-file-uploads-and-downloads-in-mcp/
- 要点：2026-11-10，MCP 官方博客介绍仍在实验中的文件扩展 io.modelcontextprotocol/files，适用于 2026-07-28 及之后的协议修订，用于在客户端与工具之间传递 PDF、CSV、压缩包等文件，而不让模型直接读取全部字节。服务器可在发现响应中声明是否接受带外或内联上传，客户端在请求元数据中声明上传/下载能力。扩展仍是可选的，目前没有参考实现，维护者希望在年底前稳定。实验仓库为 modelcontextprotocol/experimental-ext-file-uploads。
- 摘要：
  - 文件应直接到达目的地，由协议传递文件元数据和传输目标，而不是塞进模型上下文。
  - 该扩展目前是实验性、可选的，维护者邀请社区一起试，并计划在年底前争取稳定。
- 启示：
  - 若 Agent 需要把大文件交给远程工具或网关，应跟踪该扩展并注意目标地址与凭证传递的安全限制，而不是各自约定专用工具。
- 标签：mcp,extension,files,gateway
- 资源：github=https://github.com/modelcontextprotocol/experimental-ext-file-uploads

## mcp-gateway-registry 于 11 月 11 日公开两项高危公告：SSRF 与管理接口提权
- 来源：网页/文档　记录者：AI前沿者
- 链接：https://github.com/agentic-community/mcp-gateway-registry/security/advisories/GHSA-fc39-fwh3-wv5r
- 要点：2026-11-11，开源项目 mcp-gateway-registry（用于 MCP 服务器发现、访问控制和工具代理）公开两项 High 级别安全公告。GHSA-fc39-fwh3-wv5r 是服务器注册/更新接口中的服务端请求伪造，影响 1.0.3 至 1.34.0，已在 1.35.0 修复：已认证且有权注册或修改服务器的用户，可能让网关向其本不能直接访问的内部地址发起请求，在部分部署中还包括云实例元数据。GHSA-rxf3-qgpv-wxvr 是外部管理 API 认证后未做授权校验，影响 1.0.9 至 1.24.7，已在 1.25.0 修复：低权限认证用户可能把自己提升为注册表管理员。1.25.0 已包含提权修复，但仍受 SSRF 影响，建议升级到 1.35.0 或更高，并按公告审查已登记的上游地址、权限映射和日志。
- 摘要：
  - 两项高危问题分别出在上游地址校验和管理接口授权，都需要已认证用户，但权限要求不同。
  - 只升到 1.25.0 还不够，SSRF 要到 1.35.0 才修复；升级后仍需检查升级前写入的配置。
- 启示：
  - 自建 MCP Gateway 或 Registry 时，应限制谁能登记上游地址，并对管理 API 做基于角色的授权；已部署 1.34.0 及更早版本的应尽快升到 1.35.0 以上并复查配置。
- 标签：mcp,gateway,security,advisory
- 资源：docs=https://github.com/agentic-community/mcp-gateway-registry/security/advisories/GHSA-rxf3-qgpv-wxvr
