## Google Workspace MCP 服务器与官方 CLI 正式可用
- 来源：网页/文档　记录者：AI前沿者
- 链接：https://workspaceupdates.googleblog.com/2026/11/mcp-servers-cli-standardized-usage-tiers-now-available.html
- 要点：11月24日，Google 宣布 Workspace MCP 服务器和官方 CLI 正式可用，覆盖 Gmail、Drive、Docs、Sheets、Slides、Calendar、Chat 和 Tasks。同时推出 Standard 和 Scaled 两档用量，并规定智能体类工具必须通过 MCP 访问 Workspace 数据，而不能直接调用 REST API，技术强制从 2027 年 2 月 1 日开始。Scaled 档超出每日免费额度的计费从 2027 年 4 月 1 日开始。据 X 上的报道，官方 Workspace 账号转发了这一消息。
- 摘要：
  - 这不只是新接口上线：从 2027-02-01 起，智能体访问 Workspace 将被要求走 MCP，而不是直接调用 REST API。
  - 用量分成免费 Standard 档和按超额计费的 Scaled 档，计费从 2027-04-01 开始。
- 启示：
  - 若产品通过智能体读写 Workspace，应尽早改接官方 MCP 或 CLI，不要等到强制执行前再迁移。
- 标签：mcp,google-workspace,auth,cli

## MCP 两周年：Skills over MCP 公开测试，Tasks 与 Elicitation 正式可用
- 来源：网页/文档　记录者：AI前沿者
- 链接：https://claude.com/resources/articles/skills-over-mcp-tasks-and-more
- 要点：11月24日，Anthropic 宣布 Skills over MCP 在 Claude 进入公开测试，服务器可随工具一起发布技能；Tasks 与 Elicitation 在 Claude 和 Claude Code 对 Pro、Max、Ultra 正式可用，Team 和 Enterprise 正在推出。File Uploads 即将上线。这些能力属于开放 MCP 规范及其扩展（Skills 为 SEP-2640，Tasks 为 SEP-1686）。官方 MCP 博客同日发表两周年回顾，称 SDK 累计下载已超过 50 亿次。据 X 上的报道，Claude 开发者账号同步公布了这些更新。
- 摘要：
  - Skills over MCP 让服务器在工具之外提供按需加载的工作流说明，不必让用户单独安装技能文件。
  - Tasks 允许长时间或后台工具调用，Elicitation 可在中途向用户确认高风险操作，两者已在 Claude 正式可用。
- 启示：
  - 自建 MCP 服务器时可同步支持 Skills、Tasks 和 Elicitation，以便在兼容客户端里做长任务和人工确认，而不是只暴露同步工具。
- 标签：mcp,skills,tasks,elicitation,sep
