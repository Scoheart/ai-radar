## Red Hat OpenShift MCP Gateway 正式 GA，同端点兼容 2026-07-28 无状态协议与旧版本
- 来源：网页/文档　记录者：MCP
- 链接：https://www.redhat.com/en/blog/model-context-protocol-gateway-red-hat-openshift-now-generally-available
- 要点：10/16 随 Connectivity Link 1.5 GA。新增网关隔离、无状态会话、prompts/resources 支持、MCP guardrails 与安全加固；/mcp 自动协商协议版本，/mcp/stateful 强制走旧协议，新旧 MCP 服务可共用一个入口。
- 摘要：
  - 这个网关在 10/16 随 Connectivity Link 1.5 正式发布，不再是预览。同一入口要同时接 2026-07-28 的无状态协议和旧版本。
  - /mcp 会自动协商协议版本，/mcp/stateful 固定走旧协议。新旧 MCP 服务可以共用一个入口，旧客户端不必先改地址。
  - 这次同时补上了网关隔离、无状态会话、prompts/resources、MCP guardrails 和安全加固。只做协议转发，并不等于用上了这些能力。
- 启示：
  - 新旧 MCP 服务可以先共用一个入口：/mcp 协商版本，旧客户端走 /mcp/stateful。上线前用一个新客户端和一个旧客户端各打一次，确认协商没有把旧客户端送进无状态路径。
  - 网关清单里同时补上隔离、无状态会话、prompts/resources 和 guardrails，而不是只做协议转发。少任何一项，都不要把这次 GA 记成已经对齐。
  - 版本写上 Connectivity Link 1.5 和 10/16。预览期的行为不要当成这次 GA 的承诺。换小版本时重新核对 /mcp 与 /mcp/stateful 的分工。
- 标签：gateway,spec-2026-07-28,enterprise

## SEP-3440：组建 Tasks and Events 工作组，Agents 工作组降为兴趣小组
- 来源：网页/文档　记录者：MCP
- 链接：https://github.com/modelcontextprotocol/modelcontextprotocol/pull/3440
- 要点：10/20 更新的提案（阶段 proposal）：成立 Tasks and Events Working Group，并把 Agents Working Group 转为 Interest Group。同期 SEP-2848（工具调用异步审批）10/20、SEP-2643（结构化授权拒绝）10/17、SEP-2778（类型约束，draft）10/21 均有更新；SEP-2792（按请求的用户语言偏好）10/17 状态为 accepted。
- 启示：
  - SEP-3440 还在 proposal。可以开始跟踪 Tasks and Events 工作组，但不要把 Agents 工作组降为兴趣小组，理解成产品里的 Agent API 要下线。组织调整和协议字段是两件事。
  - 同一周有更新的 SEP 分开跟：2848 工具调用异步审批（10/20）、2643 结构化授权拒绝（10/17）、2778 类型约束（10/21，仍是 draft）。draft 不进实现。这里状态已经是 accepted 的是 2792，按请求携带用户语言偏好（10/17）。
  - 语言偏好按 2792 做成每个请求的字段，而不是账户级的全局设置。异步审批和结构化授权拒绝在对应 SEP 离开提案之前，继续用现有的带外流程，不要提前绑到未接受的句柄上。

## 官方 MCP servers v2.1.0 安全发布：修复 3 个参考服务器的 8 个漏洞
- 来源：网页/文档　记录者：MCP
- 链接：https://github.com/modelcontextprotocol/servers/releases/tag/v2.1.0
- 要点：10/25 发布。server-filesystem、server-everything 升到 2.0.1，mcp-server-fetch 升到 2026.10.24。最重要的是 filesystem 的符号链接竞态：检查后把父目录换成 symlink 可让写入、编辑、建目录和 move 目标逃出允许目录；Linux/macOS 已修，Windows 仅部分修复。另修了路径末尾引号/空白被检查时剥离、实际使用时保留导致可访问同名兄弟目录的问题。
- 摘要：
  - 官方 servers 在 10/25 发布 v2.1.0，修的是 3 个参考服务器里的 8 个漏洞。server-filesystem 和 server-everything 升到 2.0.1，mcp-server-fetch 升到 2026.10.24。升级时三个包的版本都要对上。
  - filesystem 的符号链接竞态发生在检查通过之后：父目录被换成符号链接，写入、编辑、建目录和移动的目标就能逃出允许目录。Linux 和 macOS 已经修好，Windows 只修了一部分。Windows 上的允许目录不能当成已经堵住。
  - 另一处是路径末尾的引号或空白。检查时被去掉，真正使用时还在，因此可以访问同名的兄弟目录。路径规范化要在检查和使用时用同一次结果。
- 启示：
  - 用了参考实现 server-filesystem、server-everything 或 mcp-server-fetch 的环境，升到 v2.1.0 对应的包版本：前两个是 2.0.1，fetch 是 2026.10.24。升级后用「检查通过再把父目录换成符号链接」做一次回归，确认写入逃出允许目录会被拒绝。
  - Windows 只修了一部分。Windows 宿主上把 filesystem 服务器的允许目录收得更紧，或先不要把不可信客户端指到这个服务器，直到部分修复的范围有官方补充。不要用 Linux 上的修复结论覆盖 Windows。
  - 路径比较前先做一次规范化，检查和使用共用这一份结果。末尾引号和空白不能在检查时剥掉、使用时又留着。同名兄弟目录放进测试用例。
- 标签：mcp,security,servers
- 资源：github=https://github.com/modelcontextprotocol/servers/security/advisories/GHSA-53mr-w429-c597；blog=https://dropagentic.com/mcp-servers-security-fix-eight-vulnerabilities/

## MCP Inspector 安全发布 2.12.0 / 1.0.3：恶意远程 Server 与 MCP App 可致本地 RCE
- 来源：网页/文档　记录者：MCP
- 链接：https://github.com/modelcontextprotocol/inspector/releases/tag/2.12.0
- 要点：10/21 发布。v1 线 1.0.3 修复两个 RCE：恶意 OAuth 回调可在 URL 里把传输切到 stdio 并执行任意命令（GHSA-4fc4-wcmh-4g86）；远程 MCP App 在同源沙箱里可窃取代理 auth token 后执行命令（GHSA-6x67-4w4w-9f3w，CVSS 9.6）。v2 线 2.12.0 修复 2.0.0–2.11.0 的三个漏洞，包括 OAuth 授权 URL 只允许 http(s) 打开。建议 npx @modelcontextprotocol/inspector@latest 升级。
- 摘要：
  - Inspector 在 10/21 发布安全版本。v1 线的 1.0.3 修了两处远程代码执行。其中一处是恶意 OAuth 回调可以在 URL 里把传输切到 stdio，并执行任意命令，公告是 GHSA-4fc4-wcmh-4g86。
  - 另一处是远程 MCP App 放在同源沙箱里，能偷走代理的 auth token 再执行命令，公告是 GHSA-6x67-4w4w-9f3w，CVSS 9.6。同源不能当成沙箱已经隔离。
  - v2 线的 2.12.0 修了 2.0.0 到 2.11.0 的三个漏洞，其中包括 OAuth 授权地址只允许 http 或 https。官方建议用 npx @modelcontextprotocol/inspector@latest 升级。
- 启示：
  - 还在 1.0.3 之前的 v1，或 2.0.0 到 2.11.0 的 v2 上时，按线升级：v1 到 1.0.3，v2 到 2.12.0，或直接用 npx 装 latest。升级前不要拿它连接不可信的远程 Server 或 MCP App。
  - OAuth 回调要禁止把传输改成 stdio，授权 URL 只允许 http 和 https。我们自己的检查器若会转发回调里的传输参数，先删掉这个能力。GHSA-4fc4-wcmh-4g86 就是这条路径。
  - MCP App 不要和代理 token 放在同源、可被页面读到的环境里。GHSA-6x67-4w4w-9f3w 的 CVSS 是 9.6，路径是窃取 token 后执行命令。沙箱换源，token 不进页面可读的存储。
- 标签：mcp,security,oauth,mcp-apps,inspector
- 资源：github=https://github.com/modelcontextprotocol/inspector/releases/tag/1.0.3；advisory=https://github.com/modelcontextprotocol/inspector/security/advisories/GHSA-6x67-4w4w-9f3w
