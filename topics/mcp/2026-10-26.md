## 官方 MCP servers v2.1.0 安全发布：修复 3 个参考服务器的 8 个漏洞
- 来源：网页/文档　记录者：MCP
- 链接：https://github.com/modelcontextprotocol/servers/releases/tag/v2.1.0
- 要点：10/25 发布。server-filesystem、server-everything 升到 2.0.1，mcp-server-fetch 升到 2026.10.24。最重要的是 filesystem 的符号链接竞态：检查后把父目录换成 symlink 可让写入、编辑、建目录和 move 目标逃出允许目录；Linux/macOS 已修，Windows 仅部分修复。另修了路径末尾引号/空白被检查时剥离、实际使用时保留导致可访问同名兄弟目录的问题。
- 内容精炼总结：
  - filesystem 在检查通过后如果父目录被换成符号链接，写入、编辑、建目录和移动都能逃出允许目录。
  - Linux 和 macOS 已经修好，Windows 只修了一部分。
  - 路径末尾的引号或空白在检查时被去掉、真正使用时还在，因此可以访问同名的兄弟目录。
- 标签：mcp,security,servers
- 资源：github=https://github.com/modelcontextprotocol/servers/security/advisories/GHSA-53mr-w429-c597；blog=https://dropagentic.com/mcp-servers-security-fix-eight-vulnerabilities/

## MCP Inspector 安全发布 2.12.0 / 1.0.3：恶意远程 Server 与 MCP App 可致本地 RCE
- 来源：网页/文档　记录者：MCP
- 链接：https://github.com/modelcontextprotocol/inspector/releases/tag/2.12.0
- 要点：10/21 发布。v1 线 1.0.3 修复两个 RCE：恶意 OAuth 回调可在 URL 里把传输切到 stdio 并执行任意命令（GHSA-4fc4-wcmh-4g86）；远程 MCP App 在同源沙箱里可窃取代理 auth token 后执行命令（GHSA-6x67-4w4w-9f3w，CVSS 9.6）。v2 线 2.12.0 修复 2.0.0–2.11.0 的三个漏洞，包括 OAuth 授权 URL 只允许 http(s) 打开。建议 npx @modelcontextprotocol/inspector@latest 升级。
- 内容精炼总结：
  - 1.0.3 修了两处远程代码执行：恶意 OAuth 回调可以把传输切到 stdio 并执行命令。
  - 放在同源沙箱里的 MCP App 能偷走代理的 auth token，再执行命令（CVSS 9.6）。
  - 2.12.0 修了 2.0.0 到 2.11.0 的三个漏洞，OAuth 授权地址只允许 http 或 https。
- 标签：mcp,security,oauth,mcp-apps,inspector
- 资源：github=https://github.com/modelcontextprotocol/inspector/releases/tag/1.0.3；advisory=https://github.com/modelcontextprotocol/inspector/security/advisories/GHSA-6x67-4w4w-9f3w
