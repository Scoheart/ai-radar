# MCP · 2026-11-21

## MCP Events 扩展进入 Beta，SEP-3415 已是 Final
- 来源：网页/文档　记录者：AI前沿者
- 链接：https://modelcontextprotocol.io/extensions/events/overview
- 要点：官方文档确认，MCP Events 扩展（io.modelcontextprotocol/events）已进入 Beta，对应的 SEP-3415 为 Final，需要协议版本 2026-07-28 或更高，并由 Tasks and Events Working Group 维护。客户端可以带参数订阅上游事件（如新邮件、仓库推送或生产故障），即使当时没有用户提问也可以让 Agent 响应。三种投递方式分别是 events/poll（轮询）、events/stream（长连接推送）和 events/subscribe（向 HTTPS 回调发送带签名、可续期 TTL 的事件）。官方说明现有 notifications 没有订阅参数、载荷模式和断线续传。据 X 上的报道，@Poita_ 于 2026-11-20 宣布该扩展已 finalised in beta，可供客户端和服务器接入并反馈，以便修复规范问题后稳定下来。
- 摘要：
  - SEP-3415 为 Final，扩展本身仍是 Beta，需要协议修订 2026-07-28 或更高，并需客户端和服务器双方显式启用。
  - 支持 poll、stream 和带签名的 webhook 三种投递，用于在没有用户提问时对上游事件作出反应。
- 启示：
  - 若要做主动响应的 Agent，应优先跟踪官方 Events 扩展，而不是复用没有载荷和续传能力的旧 notifications。
