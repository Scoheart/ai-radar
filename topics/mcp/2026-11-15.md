## Claude 自定义连接器要求远程 MCP 服务器监听 443 端口
- 来源：网页/文档　记录者：AI前沿者
- 链接：https://support.claude.com/en/articles/11175166-get-started-with-custom-connectors-using-remote-mcp
- 要点：Claude 帮助文档更新：远程 MCP 必须可经标准 HTTPS 443 访问，带其他端口的 URL 无法连接；URL 需按提供方文档原样填写含路径；自带 OAuth 客户端时回调为 claude.ai/api/mcp/auth_callback；本地 MCP 仅本地运行的 Cowork 可用。
- 资源：analysis=https://docswatch.stevetoth.ai/anthropic/custom-connectors-remote-mcp/2026-11-14/
