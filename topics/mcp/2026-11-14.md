# MCP · 2026-11-14

## MCP 官方 servers v2.4.0 修复 filesystem/git/fetch 六个漏洞
- 来源：网页/文档　记录者：AI前沿者
- 链接：https://github.com/modelcontextprotocol/servers/releases/tag/v2.4.0
- 要点：server-filesystem 升至 2.3.0（修 TOCTOU 符号链接竞争、move_file 越界），mcp-server-git 与 mcp-server-fetch 升至 2026.11.11（仓库 .git/config 不再能让只读调用执行程序；alternates/worktree 越界；IPv6 site-local 视为私有；robots.txt 路径归一化）。注意日期版本号的 npm 包管理器不会自动升级到 2.3.0，需显式安装。
- 摘要：
  - git server 的只读调用曾可因不可信仓库的 core.fsmonitor 等配置执行命令
  - Windows 上符号链接竞争与目录 junction 仍未完全修复
- 启示：
  - 检查本机 MCP 配置中的 filesystem/git/fetch 版本，日期版本需手动安装 2.3.0
- 标签：mcp,security,servers
