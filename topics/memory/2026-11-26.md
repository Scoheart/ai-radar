## Leto：按对未来回复的效用来选择记忆，而不是按对过去对话的保真度
- 来源：网页/文档　记录者：AI前沿者
- 链接：https://arxiv.org/abs/2611.33005
- 要点：11月24日，DigitalOcean 的 Shuguang Chen 与 Salman Paracha 提交 Leto（arXiv 2611.33005）。论文认为记忆的价值在于能否改进随后的回复，因而把记忆写成对未来请求效用的预测：原子事实作为索引指向原文，请求到来前用 memory replay 补上请求未明说的上下文，再按回复结果更新效用估计。作者在 6 套记忆系统、5 个基准上报告：PrefEval 准确率比所比最强系统高 16.3 个百分点，PERMA 任务完成高 3.1 分，MemoryArena 五个环境总体最好；长上下文理解与检索原始历史相当，但所用上下文 token 更少。分数来自论文，未独立复现，也未见公开实现仓库。
- 摘要：
  - 作者把记忆的写与取都改成对未来效用的预测，并用回复结果回写效用，而不是只衡量记忆是否忠实覆盖旧对话。
  - 个性化任务上的差距最大：PrefEval 比所比最强系统高 16.3 个百分点；长上下文任务则与检索原文历史持平，但上下文更短。
- 启示：
  - 评估记忆系统时，除了问“记没记住”，还应看记忆是否改变了未再提及偏好或规则时的最终行为。
- 标签：memory,leto,digitalocean,prefeval,memoryarena

## SAG-Mem：不抽取语义记忆，直接在完整对话上做词项扩展检索
- 来源：网页/文档　记录者：AI前沿者
- 链接：https://zleap.com/en/blog/sag2-agent-memory
- 要点：11月24–25日，Zleap 发布 SAG-Mem 与 SAG-Mem-Lite，并挂出技术报告（arXiv 2611.33124）。系统把完整对话按不重叠块保存，构建阶段不用 LLM 抽取或建语义图；查询时先用 BM25 初检，再由证据评估选出有用块并用词项扩展二次检索，同时为相对时间补上日历解释。官方称在 LoCoMo 和 LongMemEval 上分别得到 83.08 和 80.20，均为所评最高，其中 LongMemEval 比最强基线高 7.20 分；Lite 为 77.09 和 77.20，成本低于文中对比的 Mem0、MemOS、Zep 和 TDAM。评测代码已开源。分数来自作者，未独立复现。据 X 上的报道，有研究者同步介绍了这篇报告。
- 摘要：
  - 完整版在 LoCoMo / LongMemEval 上为 83.08 / 80.20，官方称均为所评最高；LongMemEval 比最强基线高 7.20 分。
  - Lite 用向量相似度替代证据评分，分数为 77.09 / 77.20，官方称成本低于所比的 Mem0、MemOS、Zep 和 TDAM。
- 启示：
  - 长期对话记忆不必默认先做事实抽取；先保住带日期的原文，再在查询时做互补证据扩展，是一条可复现的对照基线。
- 标签：memory,sag-mem,zleap,locomo,longmemeval
- 资源：paper=https://arxiv.org/abs/2611.33124；github=https://github.com/Zleap-AI/SAG-Mem-Benchmark；x=https://x.com/_reachsumit/status/2125663938868371750

## OpenClaw 2026.11.10 上线可选记忆组件 Knowledge：带出处的本地 Markdown 记忆库
- 来源：网页/文档　记录者：AI前沿者
- 链接：https://docs.openclaw.ai/releases/2026.11.10
- 要点：11月25日，OpenClaw 发布 2026.11.10，新增可选记忆组件 Knowledge：在本地用 Markdown 保存人物、项目、决策及带出处的摘录，可在 Control UI 中浏览并查看项目时间线。需将 plugins.slots.memory 设为 knowledge，支持热加载，且不改动已有 memory-core 数据。还支持 scribe 摄入、按关键词/别名/日期搜索、保留历史的修订，以及本地 Git 检查点。官方发布说明与 X 同步公布。这是产品能力，没有公布基准分数。
- 摘要：
  - Knowledge 默认关闭，切换后热加载，并明确不改动已有 memory-core 数据。
  - 每条声明和关系保留出处摘录，修订与合并会留下可检查的历史和本地 Git 检查点。
- 启示：
  - 给智能体加长期记忆时，应能追溯一条结论来自哪段原文，并能在不抹掉历史的前提下修正错误记忆。
- 标签：memory,openclaw,knowledge,markdown
- 资源：docs=https://docs.openclaw.ai/plugins/knowledge；github=https://github.com/openclaw/openclaw/releases/tag/v2026.11.10；x=https://x.com/openclaw/status/2125591827600531554
