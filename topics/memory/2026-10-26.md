## Raw-RAG：朴素 RAG 在 7 个设置中 6 个胜过 12 种 Agent 记忆系统
- 来源：网页/文档　记录者：记忆
- 链接：https://arxiv.org/abs/2610.30755
- 资源：github=https://github.com/Litmeb/RAW-RAG；hf=https://huggingface.co/papers/2610.30755
- 要点：原始对话按 256 token、32 重叠切窗，稠密检索 Top-128 后交叉编码器重排到 Top-15，不做任何 LLM 抽取、摘要或建图。在 LoCoMo、LongMemEval、MEME、MemoryAgentBench 上 7 个设置中 6 个第一，领先最强 Agent 记忆 0.13 至 5.53 分；加原子事实抽取让 MemoryAgentBench 总分掉 19.62 分，三种记忆管理增强需 2160 万至 1.093 亿 LLM Token，原始证据的覆盖率优势胜过变换后记忆的利用率。
- 摘要：
  - 只做切窗、稠密检索和交叉编码器重排，不做 LLM 抽取、摘要或建图。
  - 7 个设置里有 6 个排在所比较的 Agent 记忆系统前面。
  - 加上原子事实抽取后，MemoryAgentBench 总分下降 19.62；三种记忆管理增强要消耗千万到上亿 token。
- 启示：
  - 上记忆系统之前，先用切窗、检索和重排的朴素 RAG 做对照。
  - 每加一层抽取或建图，都要同时量准确率和 token 成本，确认没有把原始证据弄丢。
- 标签：RAG,baseline,benchmark

## Tether：给记忆判定绑定依赖版本，上游失效时读时撤回
- 来源：网页/文档　记录者：记忆
- 链接：https://arxiv.org/abs/2610.25123
- 资源：github=https://github.com/xiaoqi-7/tether-fallout
- 要点：原子事实记忆里每条记录写入时都为真，但上游签名密钥吊销等失效不会与下游判定同处一个检索窗口，导致 Agent 发布 62% 的上游已失效对象。Tether 写入时记录判定所依赖的确切版本，读取时撤回依赖已失效的判定，不安全发布降到 0.3%，验证调用少 37%；对比 Mem0 42%、A-Mem 与 Graphiti 9%。依赖关系若在其他会话才出现，不安全率回升到 9.4% 至 22.1%。
- 摘要：
  - 上游失效和下游判定往往不在同一个检索窗口，Agent 因此发布了 62% 已经失效的对象。
  - 写入时记下判定依赖的版本，读取时撤回失效依赖，不安全发布降到 0.3%，验证调用少 37%。
  - 作为对照，Mem0 是 42%，A-Mem 和 Graphiti 是 9%。
  - 依赖如果出现在别的会话里，不安全率会回到 9.4% 至 22.1%。
- 标签：invalidation,provenance,Mem0

## supermemory 发布 learner-1：面向任意模型的上下文内持续学习
- 来源：据 X 上的报道　记录者：记忆
- 链接：https://x.com/supermemory/status/2114491489648853364
- 要点：learner-1 对每个用户、任务和租户的上下文做抽取与离线“做梦”，在向量-图数据库上执行更新、合并、推断与遗忘，再通过 hooks 实时把记忆 Token 注入 Agent 上下文；主张学习与记忆独立于模型厂商，可跨模型、跨 Harness 携带。
