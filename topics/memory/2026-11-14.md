## ClickHouse 开源 Loom：把 Agent 记忆与代码索引放进同一数据库
- 来源：网页/文档　记录者：AI前沿者
- 链接：https://clickhouse.com/blog/introducing-loom-agent-memory-that-keeps-up-with-your-code
- 要点：ClickHouse 为自家自主贡献者 GroeneAI（3000+ 已合并 PR）构建 Loom：记忆与代码索引共存于 ClickHouse，同一权限体系，笔记关联到所描述的代码以判断是否过期，并记录每次运行。经 MCP、HTTP API、Python/TS SDK 接入，Apache-2.0。在其 ClickHouse 代码问答基准上平均答案质量从 0.78 升到 0.84。
- 摘要：
  - 此前评估的两款记忆工具只记得 Agent 写下的内容、看不到代码本身，这是 Loom 的出发点
- 启示：
  - 编码 Agent 的记忆应与代码索引绑定，记录来源以检测记忆是否随代码变更而失效
- 标签：agent-memory,coding-agent,mcp
- 资源：github=https://github.com/ClickHouse/loom

## AstroMemBench：航天具身 Agent 记忆基准，跨会话重启后 Mem0 胜 RAG 12.25 分
- 来源：网页/文档　记录者：AI前沿者
- 链接：https://arxiv.org/abs/2611.16590
- 要点：覆盖 16 个记忆子挑战、140 个模板、2240 个实例，9 个任务涉及行星表面作业、在轨服务与深空探测，确定性环境评分。同会话内 Mem0、Chain-of-Memory、LightMem 与 RAG 都优于原生 Pi Agent，但三种记忆系统并不明显优于 RAG；会话重启后 Mem0 领先 RAG 12.25 分。
- 摘要：
  - 记忆系统的优势主要体现在跨会话场景，同会话内与 RAG 差距不明显
- 启示：
  - 记忆评测要显式包含会话重启场景，否则会低估记忆系统价值
- 标签：memory-benchmark,mem0,rag
- 资源：github=https://github.com/flyingView/AstroMemBench-v1
