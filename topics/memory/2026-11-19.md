## HEAMS：从性能、隐私、安全和用户主权全面评测 Agent 记忆
- 来源：网页/文档　记录者：AI前沿者
- 链接：https://arxiv.org/abs/2611.20144
- 要点：Mila 等提出 HEAMS，把记忆系统的责任写成性能、效率、安全、隐私和用户主权五类行为要求，并用统一的 retain/recall/delete/consolidate 接口比较不同系统，同时提供原型 MilaMem 和可套在任意记忆系统上的治理层。作者发现没有一个系统在所有性能基准上都领先，而且性能分数高的系统，隐私、用户主权和安全分数可能很差。召回策略能减少不当披露，但会牺牲有用性；召回和保留策略都能提高对记忆投毒的抵抗。框架、文档和代码已开源。
- 摘要：
  - 只看任务成功率和效率，看不出记忆系统是否尊重隐私、安全和用户对删除与保留的控制。
  - 治理层（召回/保留策略）会明显改变结果：减少泄密往往要牺牲有用性，但有助于抵抗投毒。
- 启示：
  - 接入或自建记忆系统时，除了 LoCoMo 等成绩，还应测不当披露、投毒、过期记忆和按请求删除是否真的生效。
- 标签：memory-eval,HEAMS,privacy,governance
- 资源：paper=https://arxiv.org/abs/2611.20144；github=https://github.com/milatechtransfer/heams；docs=https://milatechtransfer.github.io/heams/

## 极简 RAG 记忆就能打平常见基准，真正差距在能不能把规则用上
- 来源：网页/文档　记录者：AI前沿者
- 链接：https://arxiv.org/abs/2611.22179
- 要点：芝加哥大学和伯克利等的 NeurIPS 2026 主会论文提出 Bridge：链式观察笔记、BM25 与余弦混合检索、按时间顺序呈现的极简 RAG 记忆。它在 LongMemEval-S 和 BEAM 上与此前最好成绩在自助抽样置信区间内持平，在 EverMemBench 上比最好的记忆基线高出 5.7 到 6.3 分，每次摄入或查询只调用一次模型，阅读提示约 5 千到 7 千 token。作者认为现有基准测的是检索到了什么，不是记忆能否让 Agent 在用户不再提起时应用规则或惯例，并为此设计了五类对抗探测。在 5 类探测、20 个场景里，没有一种架构全面领先：原子事实抽取（LangMem）更擅长套用规则，块摘要记忆更擅长归纳模式。
- 摘要：
  - 在常用记忆回忆基准上，极简 RAG 已能与更复杂的记忆原语打平，复杂抽取和图谱并不自动更值。
  - 真正分出高下的是：记住的规则或模式，能不能在后续动作里被用上；没有一种架构在这类探测上全面领先。
- 启示：
  - 评测 Agent 记忆时，不要只看回忆题，还要测未再提及的规则能否被执行。
- 标签：memory,RAG,benchmark,NeurIPS
- 资源：paper=https://arxiv.org/abs/2611.22179；github=https://github.com/Jingyu6/rag-in-a-trenchcoat

## StaleBench：检索排第一，也不等于用的是最新事实
- 来源：网页/文档　记录者：AI前沿者
- 链接：https://arxiv.org/abs/2611.19752
- 要点：StaleBench 专门测过期检索：同一事实有多个版本时，相似度检索无法判断哪条是当前值。基准包含 892 条真实更新事实，新旧标记来自 Wikidata 有效年份（经 TempLAMA），不来自检索分数。核心结果是：检索指标可能把策略排反——某保留策略和全部保留的对照，对每个测试问题都返回同一条作为第一名，但在不显示日期时，两个阅读器的准确率分别相差 29.5 和 65.6 分。作者提出的 Contamination@5 能排对，current@1 和 current@5 则不能。论文比较了 Mem0、Graphiti、LangMem 和复现的 ERASE，没有一种打分约定能描述全部四个系统。数据、冻结的评测器和基线已发布。该文已被 EACL 2027 Findings 接收。
- 摘要：
  - 检索第一名完全相同的两种策略，阅读器准确率可以相差几十个百分点，因为相似度分不出哪条是现在的事实。
  - Mem0、Graphiti、LangMem 和 ERASE 处理事实被替换的方式各不相同，不能用同一种检索分数来比较。
- 启示：
  - 记忆评测要单独报告是否取到了当前版本，不能只看召回或相似度排名。
- 标签：memory,staleness,StaleBench,Mem0
- 资源：paper=https://arxiv.org/abs/2611.19752；github=https://github.com/thenexuslab/stalebench-release
