## Anthropic 发布《The components of agent memory》：用 dreaming 整理跨会话记忆
- 来源：网页/文档　记录者：AI前沿者
- 链接：https://www.anthropic.com/research/components-of-agent-memory
- 要点：2026-11-06，Anthropic 发表《The components of agent memory》，把 agent memory 定义为从使用中获得、并在会话之间保留、稍后可再读的经验知识，不包括改权重、单轮上下文学习，以及用摘要替换旧轮次的 compaction。文章提出用 dreaming（在空闲时回看日志、修正或新建笔记、生成新的记忆表征，并决定下次预加载什么）来组织记忆，并引用 Letta 与 UC Berkeley 的 sleep-time compute。在 Continual Learning Bench 1.0 的数据库问答任务中，模型每题从新会话起步，只共享可持久化的 memory 目录：Claude Opus 5 首次闭合学习回路，把已验证规则、依据和陷阱写入记忆；Claude Opus 5.5 与 Claude Sonnet 5.5 同样能闭合回路。
- 摘要：
  - Anthropic 把跨会话记忆与改权重、单轮学习和 compaction 明确分开，并把 dreaming 作为离线整理机制。
  - 在 CL-Bench 1.0 上，能否把失败变成经验证的规则，是较新 Claude 模型与更早模型的关键差别。
- 启示：
  - 做长期记忆时，除了写入笔记，还应安排会话之间的离线整理，并把记住的内容当成对未来需求的预测来校验。
- 标签：agent-memory,dreaming,continual-learning,anthropic

## Graphon Labs 完成 3500 万美元 A 轮，声称在 LoCoMo、ConvoMem 和 ATM-Bench 上领先
- 来源：网页/文档　记录者：AI前沿者
- 链接：https://www.businesswire.com/news/home/20261110959095/en/Graphon-Labs-Raises-%2435M-Series-A-to-Accelerate-AGI-with-Persistent-Intelligence
- 要点：2026-11-10，Graphon Labs 宣布完成 3500 万美元 A 轮，由 RRE Ventures 领投，HP、Energy Impact Partners、Hitachi Ventures 和 Gaia VC 参投，累计融资 4330 万美元（此前种子轮 830 万美元）。公司把产品称为 Persistent Intelligence，用 graphon 框架做大规模图上的存储、检索与记忆，并称已在旧金山 49 人队、Hitachi 等企业部署。其自报结果：在 LoCoMo 上准确率 93.9%，比载入完整对话少用 58% 的 token；在 ConvoMem 上准确率 90.2%，少用 95% 的 token；在剑桥大学研究者提出的多模态 ATM-Bench 上为 81.7%，比公开榜次名高 5.0 个百分点。LoCoMo 与 ConvoMem 的对比采用 Databricks 公布的基线，以上数字均为公司自报。
- 摘要：
  - A 轮使总融资达到 4330 万美元，投资方包括 RRE、HP 和 Hitachi Ventures。
  - 公司声称在 LoCoMo、ConvoMem、ATM-Bench 上准确率居所评系统最高，但对比基线与数字需视为厂商自报。
- 启示：
  - 比较记忆系统时，应同时看准确率和检索 token 消耗，并核对比所用基线是否同一套评测协议。
