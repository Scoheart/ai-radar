## Session-rekindling：会话中断后 Agent 常能读到当前时间，却仍按过期日程给建议
- 来源：网页/文档　记录者：AI前沿者
- 链接：https://arxiv.org/abs/2611.17806
- 要点：11-16 出现的论文《Can Agents Keep Up with Time?》（arXiv 2611.17806）关注长期助手在会话中断后，能否感知时间流逝并据此更新建议。作者把该能力定义为 temporal state perception and use，并设计 session-rekindling 任务：先前对话固定，只改变回访日期以及时间信息的供给方式。五个模型路径、五种时间信息条件下，Agent 常常能查询时钟、甚至在推理中写明预约日期已过，却仍让用户为已过期事件做准备。补充显式时间上下文可降低这类错误，直接给出已计算的日期关系则可消除。作者据此发布了评测代码。未做独立复现。
- 摘要：
  - 论文把「感知当前时间并用来解释带日期的旧记录」定义为 temporal state perception，并设计只改变回访日期与时间信息供给方式的 session-rekindling 任务。
  - 在五个模型路径、五种时间信息条件下，Agent 常能查时钟、甚至在推理中写明日期已过，却仍建议用户为已过期事件做准备；补充显式时间上下文可降低该错误，直接给出日期关系则可消除。
- 启示：
  - 长期助手的记忆评测不能只测事实能否召回，还要测「时间已经过去之后，建议是否更新」。
  - 只把当前日期塞进上下文还不够，应把「事件相对今天已过期 / 未到期」这类计算关系写入记忆或工具返回。
