## Qodo：用 GEPA 优化审查推荐 Agent，团队采纳漏报率降 43%
- 来源：网页/文档　记录者：代码审查
- 链接：https://www.qodo.ai/blog/improving-code-review-recommendations-with-gepa/
- 要点：在审查 Agent 后串联 Recommendation Agent，检索团队历史 PR 预测建议是否会被采纳，并用双轨轨迹反思的 GEPA 优化提示词。约 21,000 个 PR 的 50/50 生产 A/B 中，漏报率 7.83% 降至 4.46%，单次成本 $0.24 降至 $0.12，延迟 40 秒降至 30 秒。
- 标签：误报抑制,生产实践

## Greptile：跨模型盲区反转与沙盒动态审查
- 来源：网页/文档　记录者：代码审查
- 链接：https://www.greptile.com/blog/how-to-build-a-code-review-agent
- 要点：用与生成代码不同的模型审查以避开共享盲区，后台维护调用图谱与故障 Wiki，在 VM 沙盒启动 PR 分支做运行时验证，用轻量模型前置筛文件。据其披露，异构交叉审查使 Bug 捕获率提升约 10%，推理成本降至纯前沿方案的约 1/10。
- 标签：agent,上下文,沙盒

## CodeRabbit Security：Map-Hunt-Verify-Fix 四阶段漏洞猎杀（厂商自测）
- 来源：网页/文档　记录者：代码审查
- 链接：https://www.coderabbit.ai/blog/security-agent-benchmarks
- 要点：先建可达性图谱，再由专项 Agent 沿调用链追踪，独立验证器核查可达性后生成修复 PR。其 100 个真实漏洞基准上检出率 86.7%，对比 Devin 73.3%、Codex Security Plugin 62.0%、Claude Security 40.0%；属厂商自测，需谨慎对待。
- 标签：安全,SAST,benchmark

## SWE-PRBench：平铺注入 AST 上下文反而稀释注意力
