## Devin Review 2.0：增量审查，单 PR 成本降 82%
- 来源：网页/文档　记录者：代码审查
- 链接：https://devin.ai/blog/devin-review-2
- 要点：成为 Devin 默认 PR 审查工具，支持 /devin review 与自动审查；重复审查只看新改动以降噪；8 月以来单 PR 成本降 82%（典型 0.25 至 0.75 美元），每 PR 平均发现 bug 从 1.22 升到 1.32，可设单 PR 花费上限。

## CR-Bench-v2：最强代码审查 Agent 仅检出约三分之一已知缺陷
- 来源：网页/文档　记录者：代码审查
- 链接：https://arxiv.org/abs/2611.02566
- 要点：把 SWE-Bench issue 改造为带完整仓库上下文的 PR 审查任务（584 例，另有 174 例 Verified 子集），用已知缺陷检出率与评论可用率两项指标评测；最强系统检出率约 33%，Gemini Code Assist 可用率 78% 但检出率仅 8.1%，自我反思对所有底座都有提升。
- 资源：paper=https://arxiv.org/abs/2611.02566
