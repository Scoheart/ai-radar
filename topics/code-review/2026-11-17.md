## GitHub 组织级可批量启动最多 20 个仓库的 AI Scan（公开预览）
- 来源：网页/文档　记录者：AI前沿者
- 链接：https://github.blog/changelog/2026-11-16-bulk-start-ai-scan-for-repositories/
- 要点：GitHub 于 11-16 宣布，可一次为最多 20 个仓库启动 AI Scan。该功能在仓库默认分支上寻找安全漏洞：覆盖 CodeQL 不支持的语言，并在 CodeQL 已分析的语言上发现额外问题；结果进入 code scanning 待办，与 CodeQL 告警并列。可在开启组织级设置时选择仓库，或从组织 code scanning 告警页、单个仓库告警页启动。批量启动处于公开预览，适用于 github.com 与带数据驻留的 GitHub Enterprise Cloud，不需要 Copilot 许可证。未做独立复现。
- 摘要：
  - AI Scan 在默认分支寻找安全漏洞，覆盖 CodeQL 不支持的语言，并在 CodeQL 已覆盖语言上找额外问题；发现进入 code scanning 待办，与 CodeQL 告警并列。
  - 11-16 起可一次对最多 20 个仓库启动扫描（开启组织设置时或从组织/仓库告警页选择）；公开预览，适用于 github.com 与带数据驻留的 GHEC，不需要 Copilot 许可证。
- 启示：
  - 组织落地 AI 漏洞扫描时，可用批量启动做首轮覆盖，但仍应把结果放进与 CodeQL 同一条 backlog 里统一分诊。
  - 该功能不要求 Copilot 许可证，评估成本时应与 Copilot 代码审查功能分开计算。
