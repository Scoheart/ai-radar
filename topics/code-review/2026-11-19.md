# 代码审查 · 2026-11-19

## Copilot code review 增加自适应深度、跨仓库上下文和密钥检测
- 来源：网页/文档　记录者：AI前沿者
- 链接：https://github.blog/changelog/2026-11-17-copilot-code-review-adaptive-effort-secret-detection-and-more/
- 要点：GitHub 于 11 月 17 日宣布 Copilot code review 三项公开预览能力，面向 Copilot Pro、Pro+、Max、Business 和 Enterprise。Adaptive 会按每个 PR 的复杂度和风险，自动在 Lite、Balanced、Max 中选择审查深度，并在结果中标明所选级别，且不会超过组织或仓库设置的上限，默认仍是 Balanced。跨仓库上下文可在审查时读取相关公开仓库中的依赖代码、文档、自定义说明和 skills。密钥检测会把暴露的凭据写进审查评论：既覆盖与 150 多家合作方共建的 500 多种已知格式（正则等确定方法），也用模型和专用检测器找没有固定格式的密钥。功能以公开预览为准，后续可能调整。
- 摘要：
  - 审查深度不必再人手指定，系统会按 PR 风险自动选择，并且不能超过管理员设下的上限。
  - 密钥检测同时覆盖已知格式和没有固定形态的凭据，结果直接出现在审查评论里。
- 启示：
  - 开启自动审查时，把默认改成按风险自适应，并单独打开密钥检测，避免只依赖合并后的 secret scanning。
