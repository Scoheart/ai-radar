## Farol：开源 PR 合入风险地图，接在 AI 审查之后给审批人看
- 来源：网页/文档　记录者：代码审查
- 链接：https://github.com/winnin/farol
- 要点：Winnin 开源的 CLI 与 GitHub Action，不用大模型，而用 TypeScript 类型检查器、go/types、Python ast 构建声明图，追踪变更触达的页面、API、RPC 与后台任务，结合覆盖率、安全发现和契约破坏给出 0 至 100 风险分与三档审查结论；不执行代码、不阻塞合入。第三方实测显示对有类型的契约破坏识别准确，但无类型接口是盲区。
