## PageIndex 0.7.0：统一本地/云端无向量 RAG SDK，并新增 Page Search 与结构化抽取
- 来源：网页/文档　记录者：AI前沿者
- 链接：https://github.com/VectifyAI/PageIndex/releases/tag/v0.7.0
- 要点：VectifyAI 于 11-14 发布 PageIndex 0.6.0、11-15 发布 0.7.0。项目是按文档结构建树的无向量 RAG：0.6.0 把本地与云端收成同一套客户端（默认 Flash 引擎按版面统计建树，本地模式无需服务器、向量库或 API key），并提供 agent_tools、as_claude_mcp 等 Agent/MCP 接口；0.7.0 新增云端 Page Search（可先检索文档再搜页）和按 JSON Schema 或 Pydantic 的 Page Extract，以及类型化配置——非法参数改为构造期报错，不再静默忽略。发布说明自称索引与查询都比向量 RAG 更便宜，但未在此次发行说明中给出可核对的新评测数字。
- 摘要：
  - 0.6.0 把本地与云端收成同一套无向量 RAG 客户端：默认 Flash 引擎按版面统计建树，本地不必自备向量库或 API key，并提供 agent_tools / as_claude_mcp 等 Agent 与 MCP 接口。
  - 0.7.0 新增云端 Page Search（可先找文档再搜页）和按 JSON Schema / Pydantic 的 Page Extract，以及类型化配置；非法参数改为构造期直接报错，不再静默忽略。
- 启示：
  - 做长文档问答时，可以先试用「保留文档结构、按页检索」的无向量路径，在本地无服务条件下验证，再决定是否上云或切回切片向量化。
  - 把检索（search）和结构化抽取（extract）做成独立 API，比只暴露 chat 更便于 Agent 编排。
