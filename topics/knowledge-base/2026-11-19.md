## GraphRAG Zero：索引和查询都可以不调用 LLM
- 来源：网页/文档　记录者：AI前沿者
- 链接：https://www.microsoft.com/en-us/research/story/the-evolution-of-graphrag-advancing-systems-and-evaluation-together/
- 要点：微软研究院介绍 GraphRAG Zero：相对最初的 GraphRAG，它在建索引时不再调用 LLM，也可以配成查询时同样不调用 LLM，只靠文本嵌入的几何结构做检索，延迟到亚秒级。该方案已作为选项进入 Foundry IQ（Azure AI Search）；Microsoft Discovery 计划通过 Foundry IQ 采用它。GitHub Next 的 Repo Mind Light 用 GraphRAG Zero 检索 issues 和 pull request，再配合代码与文档的实时检索，供人和编码 Agent 了解架构、归属和先前决策。
- 摘要：
  - GraphRAG 可以做成建索引和查询都不调用 LLM，把延迟压到亚秒级，适合交互式检索。
  - 同一套轻量图检索已经接到 Foundry IQ，并出现在 Repo Mind Light 的仓库理解工具里。
- 启示：
  - 如果主要需求是快速找出相关证据，可以优先试不在索引或查询阶段调用 LLM 的图检索，而不是默认上完整 GraphRAG。
- 标签：GraphRAG,Foundry-IQ,retrieval
- 资源：blog=https://www.microsoft.com/en-us/research/story/the-evolution-of-graphrag-advancing-systems-and-evaluation-together/；demo=https://githubnext.com/projects/repo-mind-light/

## Foundry IQ 上线知识图谱和检索规划模型
- 来源：网页/文档　记录者：AI前沿者
- 链接：https://techcommunity.microsoft.com/blog/azure-ai-foundry-blog/foundry-iq-introducing-knowledge-graphs-engineered-for-agents/4572683
- 要点：微软 11 月 17 日宣布 Foundry IQ 多项更新：知识图谱进入公开预览，可在索引时按本体抽取实体，或接入已有图谱，再用自然语言或 GQL 查询并带来源引用；SharePoint 知识源按使用者的 Entra 组和站点组权限过滤，已正式可用；Microsoft Retriever 1 进入公开预览，在现有索引上规划每次检索，不必再为此部署一个前沿模型。Foundry IQ 计划在 2026 年 12 月内置进每个新的 Foundry 项目，Serverless 也将在当月正式商用并提供生产 SLA。官方强调，目标是让 Agent 用更少的搜索轮次找到答案。
- 摘要：
  - 企业知识库开始把图谱、权限过滤和专门的检索规划模型放在一起，给 Agent 用，而不是只做关键词或向量搜索。
  - SharePoint 权限在查询时强制生效；Retriever 1 规划检索时不用再另外部署一个前沿模型。
- 启示：
  - 给 Agent 接企业文档时，应同时检查权限是否随查询执行，以及能否减少反复搜索。
- 标签：Foundry-IQ,knowledge-graph,SharePoint,retriever
- 资源：blog=https://techcommunity.microsoft.com/blog/azure-ai-foundry-blog/foundry-iq-introducing-knowledge-graphs-engineered-for-agents/4572683
