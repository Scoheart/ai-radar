## AutoRAGBench：从零搭建 RAG 系统，最强 Agent 平均 56.1，高于 Human-SOTA 的 44.4
- 来源：网页/文档　记录者：AI前沿者
- 链接：https://arxiv.org/abs/2611.25582
- 要点：清华大学与微博提出 AutoRAGBench，据作者所称是首个在开放代码空间评测大模型 Agent 从零开发 RAG 系统的基准，包含 9 项任务。Agent 没有起始代码或指定策略，须在单卡 H800、6 小时预算内分析数据、实现流水线并根据实验反馈迭代。9 种 Agent 配置中，GPT-6.1 Sol 搭配 Codex CLI 平均分最高，为 56.1；组合的 Human-SOTA 基线平均为 44.4。若从已有的人工系统设计出发，该配置在 7 项任务上平均还能再提高 16.6 分，并保留原方法的核心机制。
- 摘要：
  - GPT-6.1 Sol + Codex CLI 平均 56.1，高于组合 Human-SOTA 基线的 44.4。
  - 从已有人工系统出发，该配置在 7 项任务上平均再提高 16.6 分，并保留原方法核心机制。
- 启示：
  - 知识库建设可以把「让 Agent 在时限内从零搭建并迭代 RAG」本身当成一项评测，而不是只测最终问答分数。
