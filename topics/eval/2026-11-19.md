## SWE-CoWork：模拟工程组织里的编码 Agent 基准
- 来源：网页/文档　记录者：AI前沿者
- 链接：https://arxiv.org/abs/2611.20218
- 要点：TokenWave AI 发布 SWE-CoWork：101 个真实仓库开发任务，把 Agent 放进有 26 位职责和知识都有边界的同事的模拟工程组织。Agent 要从简短交接出发，向同事和工作记录收集并核对需求，再用未公开的可执行测试验收。Claude Opus 5.5 与 GPT-6 Astra 分别通过 63.84% 和 62.91% 的 fail-to-pass 测试，但完整完成任务只有 6.93% 和 7.92%；其余 9 个模型完整完成率最高 0.99%。事先给全需求能把前两者的 F2P 提高约 16 个百分点，完整完成率不变。
- 摘要：
  - 通过单项新行为测试，不等于把任务完整做完：领先模型 F2P 约 63%，完整完成率不到 8%。
  - 把完整需求提前给模型，只能提高部分测试通过率，改变不了完整完成率。
- 启示：
  - 评测编码 Agent 时，除了看测试通过率，还要单独统计任务是否全部完成、需求是否跟进到底。
- 标签：benchmark,coding-agent,SWE-CoWork
- 资源：github=https://github.com/TokenWave-AI/swe-cowork-bench；paper=https://arxiv.org/abs/2611.20218

## GitHub Copilot 评测站新增科学工作流基准和 Harness 对比
- 来源：网页/文档　记录者：AI前沿者
- 链接：https://github.blog/changelog/2026-11-17-github-copilot-benchmarks-site-adds-harness-comparisons/
- 要点：GitHub 于 11 月 17 日宣布 Copilot 评测站进入公开预览的两项更新：加入 Terminal-Bench-Science 0.1，由生命、物理、地球、数学和工程科学领域专家出题并审题，用来评测研究工作流而不只是写代码；新增 Harnesses 视图，在同一模型和同一中等推理强度下对比 GitHub Copilot CLI、Claude Code 和 Codex CLI 的解决率与单任务平均成本，并给出约 95% 的自助抽样区间。只比较完全匹配的模型对，Copilot Fusion 等无法配对的配置不纳入对比。
- 摘要：
  - 同一模型换一套 Agent 脚手架，解决率和成本也会变，评测站把这个差异单独展示出来。
  - Terminal-Bench-Science 0.1 把评测范围从写代码扩展到科研工作流。
- 启示：
  - 对比模型时，应固定脚手架和推理强度，并把成本和解决率放在一起看。
- 标签：leaderboard,Terminal-Bench,harness,GitHub
- 资源：blog=https://github.blog/changelog/2026-11-17-github-copilot-benchmarks-site-adds-harness-comparisons/；leaderboard=https://benchmarks.github.com/

## Omni-Workspace：多模态工作区深度研究基准
- 来源：网页/文档　记录者：AI前沿者
- 链接：https://arxiv.org/abs/2611.19202
- 要点：Omni-Workspace 包含 380 个深度研究风格任务，覆盖四种多模态工作区类型和两个难度，要求 Agent 查看并处理工作区文件、必要时检索外部信息、跨文件和跨模态整合证据，并产出符合明确要求的制品。作者评测了 18 个代表性模型，最好的平均分只有 65.93，并指出多模态上下文膨胀和任务状态漂移是反复出现的问题。论文还提出了结合多模态工作记忆管理的轻量方法 OmniFocus。
- 摘要：
  - 18 个模型里最好的平均分只有 65.93，现有模型在长程多模态工作区任务上仍有明显缺口。
  - 作者把常见失败归结为上下文膨胀和任务状态漂移。
- 标签：benchmark,multimodal,workspace
- 资源：paper=https://arxiv.org/abs/2611.19202
