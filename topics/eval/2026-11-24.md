## Kotlin Benchmark 2.0：加入闭源任务并限制网络，防止查找已公开修复
- 来源：网页/文档　记录者：AI前沿者
- 链接：https://blog.jetbrains.com/kotlin/2026/11/kotlin-benchmark-2-0-how-ai-coding-agents-handle-harder-tasks-and-closed-source-code/
- 要点：2026-11-23，JetBrains 发布 Kotlin Benchmark 2.0。任务集改为 100 道中高复杂度、需跨文件修改的仓库级题目：70 道来自 25 个开源仓库（Android 30、后端 20、Kotlin Multiplatform 10、库与工具 10），30 道来自 JetBrains 内部服务端 Kotlin 项目。开源任务在更严格的沙箱中求解，只允许访问模型本身，依赖预先缓存，仓库历史被隐藏，以减少查找已公开修复的刷分；闭源任务仍可联网，因其修复并未公开。每套配置限时 30 分钟、全量跑三遍。完整套件最高分为 Claude Code + Opus 5.5，通过率 75.3%，平均每题约 0.84 美元；其余 12 套配置通过率为 54.3%–73.7%，平均每题约 0.02–3.14 美元。开源子集上 Claude Code + Fable 5.1 为 86.2%（约 2.38 美元），Claude Code + Opus 5.5 为 84.8%（约 0.68 美元）。闭源子集上 Antigravity CLI + Gemini 3.8 Flash 为 60%（约 1.74 美元），OpenCode + DeepSeek V4.1 Flash 为 58.9%（约 0.08 美元）。官方写明新套件更难，分数不可与上一版直接比较；限制联网不能排除开源修复进入训练数据，这也是保留 30 道闭源题的原因。排行榜还给出平均费用、token 数、延迟和步数。
- 摘要：
  - 2.0 共 100 题：70 道开源、30 道 JetBrains 闭源；开源任务限制联网并隐藏仓库历史，以减少查找已公开修复。
  - 完整套件最高为 Claude Code + Opus 5.5，通过率 75.3%、平均每题约 0.84 美元；闭源子集上 Antigravity CLI + Gemini 3.8 Flash 为 60%，OpenCode + DeepSeek V4.1 Flash 为 58.9%、约 0.08 美元。
  - 官方写明新套件更难，分数不可与上一版直接比较；限制联网并不能排除开源修复进入训练数据。
- 启示：
  - 评测公开仓库级任务时，应默认考虑“查找已有修复”这类刷分路径，并用断网沙箱、隐藏提交历史或闭源题来对照。
  - 选择编程 Agent 配置时，应同时看通过率、费用和开源/闭源拆分，而不是只看总分。

## Hugging Face 发布构建与维护智能体评测的指南
- 来源：网页/文档　记录者：AI前沿者
- 链接：https://huggingface.co/blog/agentic-evals
- 要点：2026-11-23，Avijit Ghosh、ben burtenshaw 和 Irene Solaiman 在 Hugging Face 博客发布《How to build and maintain an agentic evaluation》。文章把评测分成问答、智能体、多智能体/群体三个阶段，并按一个任务走完从主张到报告分数的八个步骤；同时讨论任务和打分器出错后如何发现与修正，以及评测各组件哪些应公开、哪些可以保留。文中称 Hub 上约有 3500 个评测排行榜，过去一年评测数据集约增至 17000（约 16 倍），并提到近期加入的 Traces、Benchmarks、Environments 等与智能体评测相关的抽象。这是方法与平台指南，不是新的基准或排行榜结果。
- 摘要：
  - 指南把智能体评测拆成从主张到报告分数的步骤，并讨论打分器错误与开源策略；同时提到 Hub 上约 3500 个评测排行榜，以及 Traces、Benchmarks、Environments 等抽象。
- 启示：
  - 自建智能体评测时，应把任务、环境、轨迹和打分器一并设计，并预先考虑哪些部分必须公开才能被复核。
- 标签：eval,huggingface,agentic-evals,methodology
