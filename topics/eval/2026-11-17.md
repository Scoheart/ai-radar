## WebArena-Pro：20 个自托管站点、含音视频的可复现 Web Agent 基准
- 来源：网页/文档　记录者：AI前沿者
- 链接：https://arxiv.org/abs/2611.17955
- 要点：McGill / Mila 等在 11-16 公布 WebArena-Pro（arXiv 2611.17955，NeurIPS 2026 E&D）：300 个任务覆盖 20 个自托管 Web 应用、6 类领域（生产力、沟通、分析、业务运营、设计与媒体、旅行），把音频和视频作为与文本、视觉并列的核心观察，并提供 transcribe()、extract_frames() 等动作。任务在隔离环境中运行，支持可复现的并行评测。论文报告最佳成绩为 Codex + GPT 6.1 Sol 与 Claude Code + Claude Opus 5.5 同为 62.3%，OpenCode + Kimi 3.1 Pro 为 60.7%；GenericAgent 最强配置（Gemini 3.1 Pro omni 与 Gemma4 31B）均为 30.3%。未做独立复现。
- 摘要：
  - 300 个任务覆盖 20 个自托管应用、6 类领域，把音频和视频作为与文本/视觉并列的核心观察，并提供 transcribe / extract_frames 等动作；任务在隔离环境中可并行、可复现。
  - 论文报告最佳成绩为 Codex + GPT 6.1 Sol 与 Claude Code + Claude Opus 5.5 同为 62.3%，OpenCode + Kimi 3.1 Pro 为 60.7%；GenericAgent 最强配置仅 30.3%。
- 启示：
  - 评测 Web Agent 时，站点覆盖面和可复现性常常冲突；可用自托管多站点基准同时测异构界面与音视频，把会漂移的 live 站点留给补充检验。
  - 专用编码 Agent（Codex / Claude Code）明显强于通用 Agent 配置，比较时应分开报告，不要混成一张总表。
- 标签：webarena,web-agent,multimodal,benchmark
- 资源：github=https://github.com/McGill-NLP/webarena-pro；dataset=https://huggingface.co/datasets/WebArena-Pro/WebArena-Pro；demo=https://webarena-pro.github.io/

## Amazon 开源 BenchProofer，并把 SWE-Bench Verified 500 题做成形式化验证基准 SWE-Proof
- 来源：网页/文档　记录者：AI前沿者
- 链接：https://www.amazon.science/blog/benchproofer-formally-verified-coding-benchmarks-on-demand
- 要点：Amazon Science 于 11-16 发文并开源 BenchProofer：把已有编码基准的参考补丁形式化为规范、可验证实现和机器检查证明，再用测试与对抗审计核对实现是否与仓库补丁一致。同期发布 SWE-Proof，为 SWE-Bench Verified 全部 500 题补充规范、实现和证明。博客称 Claude Opus 4.8 在原测试上通过 425/500（85.0%），但审计用参考规范生成的补测让其中 134 题失败；人工抽查 41 个被标记补丁中 21 个确有缺陷。在 Lean 后端、给定 BenchProofer 规范时，验证通过率为 Opus 4.8 的 84.6%→93.6%、GPT-5.5 的 79.6%→94.4%（分母均为 500）。仓库许可为 CC BY-NC 4.0，声明仅供学术复现且不接受 PR。论文正文更早见于 arXiv 2609.21190。未做独立复现。
- 摘要：
  - 工具把已有测试基准形式化为规范、可验证实现和机器检查证明；同期发布 SWE-Proof，覆盖 SWE-Bench Verified 全部 500 题（CC BY-NC 4.0，仅供学术复现，不接受 PR）。
  - 博客称 Opus 4.8 在原测试上通过 425/500（85.0%），审计补测使其中 134 题失败；人工抽查 41 个被标记补丁中 21 个确有缺陷。给定官方规范后，Lean 验证通过率为 Opus 4.8 的 84.6%→93.6%、GPT-5.5 的 79.6%→94.4%。
- 启示：
  - 只看测试通过率会高估编码 Agent：应同时报告「原测试通过」和「形式化验证 / 对抗补测通过」。
  - 把规范交给 Agent 能明显提高验证通过率，但让 Agent 自写规范仍然困难，评测需分开报告「自写规范」与「给定规范」两档。
- 标签：swe-bench,formal-verification,benchmark,coding-agent
- 资源：github=https://github.com/amazon-science/BenchProofer；paper=https://arxiv.org/abs/2609.21190
